# 🚀 CloudVault Quick Start\n\n## One-Click Startup\n\nChoose your operating system and click the link below to start the application:\n\n### **Option 1: Automatic Startup Script** (Recommended)\n\n#### For Mac/Linux:\n```bash\nbash start.sh\n```\n\n#### For Windows:\n```bash\nstart.bat\n```\n\nThe script will automatically:\n1. ✅ Check for Node.js\n2. ✅ Install dependencies\n3. ✅ Start the backend server\n4. ✅ Launch your chosen platform (Android, iOS, or Web)\n\n---\n\n### **Option 2: Manual Startup (If Script Doesn't Work)\n\n#### Step 1: Start the Backend\n```bash\ncd backend\nnpm install\nnpm start\n```\n\nYou should see:\n```\nCloudVault Backend running on http://localhost:5000\n```\n\n#### Step 2: Open a New Terminal & Start Mobile App\n```bash\ncd mobile\nnpm install\n\n# Choose one:\nnpm run android    # For Android\nnpm run ios        # For iOS\nnpm run web        # For Web\n```\n\n---\n\n## 📱 Direct Links\n\n### **View Your CloudVault Project:**\n🔗 [Open Project on GitHub](https://github.com/ALLXRUDEMENTRY999/ALLXRUDEMENTRY999/tree/cloud-storage-app)\n\n### **Backend API:**\n🔗 [Backend Health Check](http://localhost:5000/api/health)\n\n---\n\n## 🎯 First Time Setup Checklist\n\n- [ ] Node.js installed? ([Download Here](https://nodejs.org/))\n- [ ] Downloaded project files?\n- [ ] Opened terminal in project directory?\n- [ ] Run startup script (or manual commands)?\n- [ ] Choose your platform (Android/iOS/Web)?\n- [ ] App should open automatically!\n\n---\n\n## 🆘 Troubleshooting\n\n### \"command not found: npm\"\n- Install Node.js from https://nodejs.org/\n\n### \"Port 5000 already in use\"\n- Change PORT in backend/.env file\n- Or kill the process: `lsof -ti:5000 | xargs kill -9` (Mac/Linux)\n\n### \"React Native command not found\"\n- Install globally: `npm install -g react-native-cli`\n\n### \"Metro bundler won't start\"\n- Clear cache: `npm start -- --reset-cache`\n- Delete node_modules and reinstall: `rm -rf node_modules && npm install`\n\n---\n\n## 📞 Support\n\nFor more details, see:\n- [Full README](README.md)\n- [Setup Guide](docs/SETUP.md)\n\n**Happy Cloud Storage! ☁️**\n
